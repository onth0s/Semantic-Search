COMMAND: __main__.py find
=========================
                                                                               
 Usage: __main__.py find [OPTIONS] QUERY [ROOT_DIR]                            
                                                                               
 Search for filesystem paths matching QUERY.                                   
 QUERY is a vague, colloquial, fuzzy, or wildcard-based (e.g. *.txt)           
 description of the path you're looking for. Supports configured category      
 keyword tags (e.g. docs, pics) exact, fuzzy, and phonetic matching.           
 ROOT_DIR (default: current directory) is the starting point for the search.   
                                                                               
┌─ Options ───────────────────────────────────────────────────────────────────┐
│ --root             PATH     Root directory to search (overrides ROOT_DIR    │
│                             argument).                                      │
│ --depth            INTEGER  Maximum folder depth to traverse. [default: 5]  │
│ --min-confidence   FLOAT    Minimum confidence score (0.0-1.0) to return a  │
│                             match. [default: 0.3]                           │
│ --top-n            INTEGER  Number of results to return. [default: 5]       │
│ --non-interactive           Disable interactive fallback (H9).              │
│ --no-index                  Force on-the-fly traversal scan.                │
│ --json                      Output structured JSON instead of styled text.  │
│ --verbose                   Enable detailed under-the-hood diagnostics,     │
│                             category matching, and handler execution logs.  │
│ --latest                    Sort matches to return the newest path.         │
│ --largest                   Sort matches to return the largest file.        │
│ --ext              TEXT     Filter candidates to keep only those with       │
│                             specified extension.                            │
│ --help                      Show this message and exit.                     │
└─────────────────────────────────────────────────────────────────────────────┘
